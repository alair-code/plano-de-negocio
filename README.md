# Business Plan Builder

Aplicação web para planejar, analisar e organizar um negócio em sete módulos: oportunidade, ambientes, plano de negócios, viabilidade financeira, planos complementares, exportação e gestão.

## Como usar

1. Abra `index.html` em um servidor estático ou pela publicação do GitHub Pages.
2. Navegue pelos módulos usando o menu lateral.
3. Preencha os campos; os rascunhos são salvos automaticamente no armazenamento local do navegador.
4. Use a área de exportação para gerar arquivos e imprimir o plano.

## Tecnologias

- HTML5
- CSS3 responsivo
- JavaScript sem framework
- LocalStorage para salvar e recuperar os dados no mesmo navegador

## Observações

- Os dados ficam no navegador e não são enviados automaticamente para um banco de dados.
- Limpar os dados do navegador pode apagar os rascunhos armazenados.
- Para continuar em outro dispositivo, exporte o plano e transfira o arquivo manualmente.
- O projeto é estático e pode ser publicado no GitHub Pages.
